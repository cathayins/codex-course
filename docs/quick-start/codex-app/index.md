# Codex App

<p class="lesson-lead">Codex App 是 Codex 的桌面工作介面。它可以開啟指定的資料夾，讓 Codex 在授權範圍內讀寫檔案、執行指令，並把成果留在原本的工作環境。</p>

  <div class="app-overview-zones">
